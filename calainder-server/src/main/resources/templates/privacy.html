개인정보처리방침

시행일: 2026년 4월 21일

Calainder(이하 "서비스")는 사용자의 일정을 더 편리하게 관리할 수 있도록 텍스트 및 이미지 기반 일정 분석, Google Calendar 연동, 학교 E-Class 일정 가져오기 기능을 제공합니다. 본 개인정보처리방침은 서비스가 어떤 개인정보를 수집하고, 어떻게 이용하며, 어떻게 보호하는지 설명합니다.

서비스는 개인 포트폴리오 및 베타 테스트 목적으로 제공됩니다. 사용자는 AI 분석 결과와 캘린더 반영 내용을 직접 확인한 후 이용해야 합니다.

1. 수집하는 개인정보 항목

서비스는 다음과 같은 정보를 처리할 수 있습니다.

  • Google OAuth 로그인 정보: Google 계정 식별 정보, 이메일, 프로필 정보
  • Google Calendar 일정 정보: 일정 제목, 설명, 장소, 시작/종료 일시, 반복 정보, 알림 정보, Google Calendar 이벤트 ID
  • AI 일정 분석 요청 정보: 사용자가 입력한 텍스트, 업로드한 이미지 파일, 이미지에 포함된 일정 관련 정보
  • 학교 E-Class 일정 가져오기 정보: 사용자가 입력한 학교 계정 ID와 비밀번호
  • 서비스 이용 과정에서 발생하는 오류 정보 및 요청 처리 로그

2. 개인정보의 수집 및 이용 목적

서비스는 수집한 정보를 다음 목적을 위해 사용합니다.

  • Google 계정을 통한 사용자 인증
  • 사용자의 Google Calendar 일정 등록, 조회, 수정, 삭제
  • 텍스트 또는 이미지에서 일정 정보 분석
  • 학교 E-Class 학습 일정 및 과제 일정 가져오기
  • 서비스 오류 확인, 기능 개선, 사용자 문의 대응

3. 학교 계정 정보 처리

학교 E-Class 일정 가져오기 기능에서 입력된 학교 계정 ID와 비밀번호는 일정 조회 요청을 처리하기 위해서만 사용됩니다. 해당 정보는 서버에 영구 저장하지 않으며, 요청 처리 과정에서 암호화되어 크롤러 모듈로 전달됩니다.

4. Google 사용자 데이터 처리

서비스는 사용자가 동의한 범위 내에서 Google Calendar API를 사용합니다. Google API로부터 받은 정보는 사용자가 요청한 일정 관리 기능을 제공하거나 개선하기 위한 목적으로만 사용됩니다. 서비스는 Google 사용자 데이터를 광고, 판매, 재판매, 비사용자 대상 AI 모델 학습 목적으로 사용하지 않습니다.

5. 개인정보의 보유 및 이용 기간

  • Google Calendar 일정 정보는 사용자의 Google Calendar에 저장되며, 서비스가 별도 DB에 영구 저장하지 않습니다.
  • AI 분석을 위해 업로드된 이미지는 요청 처리 후 별도 저장하지 않습니다.
  • 학교 계정 정보는 일정 조회 요청 처리 후 저장하지 않습니다.
  • 오류 로그는 서비스 안정성 확인을 위해 필요한 기간 동안 보관될 수 있습니다.

6. 개인정보의 제3자 제공 및 처리 위탁

서비스는 사용자의 개인정보를 원칙적으로 제3자에게 판매하거나 제공하지 않습니다. 다만 서비스 제공을 위해 다음 외부 서비스를 사용할 수 있습니다.

  • Google: Google OAuth 로그인 및 Google Calendar API 연동
  • OpenAI: 사용자가 입력하거나 업로드한 일정 관련 텍스트 및 이미지 분석

7. 개인정보의 국외 이전

Google 및 OpenAI와 같은 해외 서비스 제공자의 API를 사용하는 과정에서 일정 분석 또는 캘린더 연동에 필요한 정보가 국외 서버로 전송될 수 있습니다. 전송되는 정보는 사용자가 요청한 기능 제공을 위해 필요한 범위로 제한됩니다.

8. 개인정보의 파기

서비스가 별도로 저장하지 않는 정보는 요청 처리 완료 후 즉시 파기됩니다. 별도 로그로 남는 정보가 있는 경우 목적 달성 후 안전하게 삭제합니다.

9. 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • Google 계정 권한 철회
  • Google Calendar에서 생성된 일정 직접 수정 또는 삭제
  • 서비스 이용 중단 요청
  • 개인정보 처리 관련 문의

Google 계정 권한은 Google 계정 권한 관리 페이지에서 철회할 수 있습니다.

10. 개인정보 보호를 위한 조치

  • 학교 계정 정보 암호화 전송
  • 환경 변수를 통한 API Key 및 Secret 관리
  • 민감 정보의 Git 저장소 커밋 방지
  • 불필요한 개인정보 저장 최소화

11. 개인정보처리방침 변경

본 개인정보처리방침은 서비스 개선, 법령 변경, 외부 API 정책 변경에 따라 수정될 수 있습니다. 변경 시 서비스 화면 또는 저장소를 통해 안내합니다.

12. 문의
